# MiTV-MZTU1: памятка

Проверенная версия — **2.7-mztu1.2 (11)**, пакет `com.gathin.tvhome`.
Home и автоматический запуск после перезагрузки проверены на телевизоре.
Работают громкость, запуск приложений, «Источники» и «Настройки».
Погода MET Norway, курсы CoinGecko и фотографии с GitHub загружаются напрямую.
Почасовая смена обоев реализована и проверена тестами; полное часовое
наблюдение на телевизоре отдельно не проводилось.

## Повседневное использование

В доке: Vokino → SmartTube → Кинопоиск → VK Видео → Kick → VLC.
Остальные приложения доступны ниже. Google Play и системные сервисы сохранены.
Голосовой поиск, трансляция и службы обновления прошивки не отключались.

Обои загружаются в разрешении 3840×2160 и меняются раз в час, пока главный
экран виден. При сбое остаётся последняя сохранённая фотография.
В выборе обоев **None** выключает автоматические фотографии,
**Theme default** возвращает их. Выбранный вручную локальный фон имеет приоритет.
Сетевые запросы останавливаются при уходе с главного экрана.

## Что отключено

В ходе настройки отключены для пользователя 0:

- `com.miui.tv.analytics` и `com.xiaomi.statistic` — телеметрия;
- `com.google.android.tvlauncher` — прежний Home;
- `com.google.android.tungsten.setupwraith` — мастер настройки;
- `com.mitv.tvhome.atv` — PatchWall, который открывался при включении.

Четыре пакета были отключены ещё до настройки и оставлены в таком состоянии:
`com.mediatek.dtv.tvinput.isdbtuner`, `com.iwedia.tvinput`,
`com.mediatek.dtv.tvinput.atsctuner`, `com.amazon.amazonvideo.livingroom`.
Не следует включать все девять пакетов одной общей командой восстановления.
Удаление системных APK и root не применялись. Изменение отдельного компонента
BannerLogoB было отклонено прошивкой; его состояние не менялось.

## Резервные копии и возврат

Копии и сценарии восстановления находятся на Windows-компьютере,
а не в приложении и не в публичном репозитории:

- `%USERPROFILE%\TV-backup-*` — исходные списки пакетов и настройки;
- `%USERPROFILE%\Downloads\TV-switch-*\restore-home.cmd` — возврат
  штатного Home с восстановлением пакетов лаунчера и мастера настройки;
- `%USERPROFILE%\Downloads\TV-patchwall-*\restore-patchwall.cmd` — PatchWall;
- `%USERPROFILE%\Downloads\TV-changes-*\restore-telemetry.cmd` — телеметрия.

Для полного возврата сначала выполните `restore-home.cmd` именно из
каталога **TV-switch**, затем сценарии PatchWall и телеметрии.
Сценарий из TV-startup от неудавшегося изменения компонента не требуется.
Перед заводским сбросом также восстановите штатный Home и мастер настройки.
Сохраните эти каталоги на другом диске; не публикуйте полные резервные копии.

Отладка выключена, разрешения отозваны; пользователь подтвердил отказ
соединения на TCP 5555 после перезагрузки. Для обслуживания потребуется
временно включить отладку и заново разрешить подключение компьютера.
После обслуживания снова выключите её.

## Сборка и обновление

Нужны JDK 17, Android SDK 34, build-tools 34.0.0. В подготовленной облачной среде:

```bash
source /workspace/.tv-onboarding/env.sh
cd /workspace/tv/launcher
./gradlew --no-daemon --max-workers=2 testReleaseUnitTest lintRelease assembleRelease
```

APK: `launcher/app/build/outputs/apk/release/app-release.apk`.
Последняя проверка: 275 тестов, без ошибок и пропусков; Android lint без ошибок;
APK совпадает по SHA-256 с установленной версией:

```text
649a9541c2dd605286e7efb91d25cbb830f49ef5c9b6f27e4827c7cbe5851f13
```

Сборка использует локальный ключ разработки. Сохраните его приватно для будущих
обновлений; новый ключ не позволит установить обновление поверх текущего приложения.
Ключ не включён в архив исходников. Не удаляйте данные приложения ради обновления.

В PowerShell из каталога platform-tools установка готового APK выполняется отдельно
от настройки Home. Подставьте текущий адрес ТВ и путь к проверенному APK:

```powershell
$tv = "IP_ТВ:5555"
$apk = "C:\путь\к\проверенному.apk"
.\adb.exe -s $tv push $apk /data/local/tmp/tvhome-update.apk
# Продолжайте только если передача завершилась успешно.
.\adb.exe -s $tv shell pm install -r /data/local/tmp/tvhome-update.apk
# Продолжайте только после Success.
.\adb.exe -s $tv shell am start -W -n com.gathin.tvhome/.MainActivity
```

Унаследованные `build-and-install` сценарии не используйте: они рассчитаны
на другую структуру проекта и могут менять системный Home.
Архивная версия 2.7-mztu1.3 содержит эксперимент запуска по загрузке;
она не нужна для подтверждённой рабочей конфигурации.
